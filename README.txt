============================================
  序列帧动画编辑器（便携版）
============================================

【如何启动】
方法一（推荐，无需安装任何软件）：
  双击本文件夹里的  server.exe
  然后打开浏览器，访问  http://localhost:8765/

方法二（备选，需安装 Python 3）：
  双击 启动编辑器.bat
  或手动运行：python sequence-editor\server.py
  然后打开浏览器，访问  http://localhost:8765/

停止服务：在启动程序的窗口里按 Ctrl+C，或直接关闭窗口。

------------------------------------------------
【这是什么】
一个本地网页工具，用来浏览、播放各角色的序列帧动画
（Walk / Harm / Hit / Death / Shoot 等动作），
并支持导入新动作、导出 GIF 动图、导出雪碧图。

【主要功能】
- 左侧选择角色（支持搜索）
- 顶部切换动作标签，自动播放动画
- 播放/暂停、上一帧/下一帧、调速、循环、洋葱皮、缩放
- 底部帧带点击跳帧
- 「＋ 导入动作」：在界面里直接选图，为新动作建序列帧
- 「导出 GIF」「导出雪碧图」：导出当前动作

【数据在哪里】
- 每个角色一个文件夹（如 abo/），内含 PNG/ 序列帧图片
- 想新增角色或动作：往对应文件夹的 PNG/ 里放
  「角色名-动作名_帧号.png」命名的图片即可（详见 sequence-editor\README.md）

【注意事项】
- 端口固定为 8765，若被占用，请修改 sequence-editor\server.py 的 PORT
- 全部在本地运行，不联网，可放心使用
- 角色形象对照表.xlsx 是各角色 Harm_0 形象的表格，可另作参考

------------------------------------------------
【想在新电脑上继续开发这个编辑器？】
完全可以！本文件夹里就是全部源码，默认的 server.exe 只是源码的打包快照。

- 需要：Python 3（服务器本身只用标准库，零第三方依赖）
- 开发流程：改 sequence-editor\ 里的代码 → 在 sequence-editor\ 目录运行
  python server.py 测试（注意：改代码后要用 python 跑源码，不要用 exe）
- 重新打包 exe：pip install pyinstaller 后执行
  pyinstaller --onefile --name server --clean sequence-editor\server.py，
  再把生成的 server.exe 放到本文件夹根目录
- 详细开发说明见 sequence-editor\README.md 的「在新电脑上继续开发」一节
